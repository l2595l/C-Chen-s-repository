## 0. 一句话概括

> 每次能让"和"增加 1 的那个操作，**恰好不去碰参与比较的那两个数**，所以失衡状态能无限滚雪球；
> 而升序状态必须先花 τ 步"自残"才能启动雪球。
> 于是单实验室可达和 $F(m)=\max(s,\ s+m-2\tau)$，各实验室代价相加后对答案**二分**。

---

## 1. 题目模型

- 有 $n$ 个实验室，每个实验室有三个读数 $(a,b,c)$，**位置是有意义的**（sgn 比较的是固定位置 $a-b$、$a-c$、$b-c$）。
- 一次操作选定一个实验室，执行三选一：

$$
c \leftarrow c+\operatorname{sgn}(a-b),\qquad
b \leftarrow b+\operatorname{sgn}(a-c),\qquad
a \leftarrow a+\operatorname{sgn}(b-c)
$$

其中 $\operatorname{sgn}(x)=+1/0/-1$（正/零/负）。

- 总共最多 $k$ 次操作（$k\le 10^{18}$）。
- **目标：最大化所有实验室 $a+b+c$ 中的最小值。**

记 $s=a+b+c$。注意每次操作对 $s$ 的改变量恰好是 $\operatorname{sgn}(\cdot)\in\{-1,0,+1\}$。

---

## 2. 第一层：单个实验室能涨多快？

### 2.1 全部秘密在这里

列出三个操作里能让 $s$ **增加**的分支：

| 操作 | 增长条件 | 增长时谁变、谁**不变** |
|---|---|---|
| 1 | $a>b$ | 只有 $c$ 加 1，**$a$、$b$ 完全不动** |
| 2 | $a>c$ | 只有 $b$ 加 1，**$a$、$c$ 完全不动** |
| 3 | $b>c$ | 只有 $a$ 加 1，**$b$、$c$ 完全不动** |

> **关键结论**：能让和 +1 的那一步，**恰好不动用来比较的那两个数**。
> 所以"失衡"被永久保留 —— 同一条操作可以无限重复。

### 2.2 逆序（非升序）= 永动机

条件 $a\le b\le c$ 的否定是 $a>b \lor b>c$。

- 若 $a>b$：执行操作 1，$c$ 加 1，$a,b$ 不动，$a>b$ 仍成立 → 可无限重复。
- 若 $b>c$：执行操作 3，$a$ 加 1，$b,c$ 不动，$b>c$ 仍成立 → 可无限重复。

因此（$\tau=0$）：

$$
F(m)=s+m
$$

### 2.3 升序 = 必须先"自残"

若 $a\le b\le c$，三个 sgn 全部 $\le 0$，所以：

- 操作 1（当 $a<b$）→ $c$ 减 1；$a=b$ 时空转；
- 操作 2（当 $a<c$）→ $b$ 减 1；
- 操作 3（当 $b<c$）→ $a$ 减 1。

**要么空转、要么让和 −1，永远不可能增加**，而且只会把数往下压、让顺序更"升序"。
所以必须先把升序破坏掉：

- **路线 A（压 $b$）**：反复操作 2，$b$ 每次 −1（只要 $a<c$），花 $b-a$ 步让 $b=a$；再补 1 步得 $b=a-1<a$，出现 $a>b$。共 $(b-a)+1$ 步。
- **路线 B（压 $c$）**：反复操作 1，$c$ 每次 −1（只要 $a<b$），花 $c-b$ 步让 $c=b$；再补 1 步得 $c=b-1<b$，出现 $b>c$。共 $(c-b)+1$ 步。

取更省的一条：

$$
\tau=\min(b-a,\;c-b)+1
$$

这 τ 步每步都是 −1（把和从 $s$ 压到 $s-\tau$），之后进入永动机，每步 +1：

$$
F(m)=\max\bigl(s,\ \underbrace{s-\tau}_{\text{自残}}+\underbrace{(m-\tau)}_{\text{爬升}}\bigr)=\max(s,\ s+m-2\tau)
$$

> $\max$ 里的 $s$ 对应"一次都不操作"（题目允许用少于 m 次操作）。

### 2.4 死局：$a=b=c$

三个 sgn 恒为 0，任何操作都是空转：

$$
F(m)=s \qquad (\text{永远不变})
$$

它是全局的**天花板**。

### 2.5 汇总表

| 情形 | 判据 | $\tau$ | $F(m)$ |
|---|---|---|---|
| 逆序 | $a>b$ 或 $b>c$ | $0$ | $s+m$ |
| 升序 | $a\le b\le c$ 且不全等 | $\min(b-a,\,c-b)+1$ | $\max(s,\ s+m-2\tau)$ |
| 死局 | $a=b=c$ | $+\infty$ | $s$ |

**小例验证**（(1,2,3)：$s=6$，升序，$\tau=\min(1,1)+1=2$ → $F(m)=\max(6,\ m+2)$）：

- $F(0..4)=6$，$F(5)=7$，$F(6)=8$，$F(8)=10$ —— 与上图画的红线一致。

## 3. 第二层：从"一个"推广到"所有"

### 3.1 总代价 = 各实验室代价**相加**

**因为一次操作只作用于一个实验室**（操作里的 $a,b,c$ 属于同一个三元组）。所以各实验室完全独立、互不抢步数：

- 若 A 至少要 5 步、B 至少要 1 步才达标，则**无论怎么安排顺序**，总步数**至少**是 $5+1=6$；
- 而 6 步也**确实够**：把 5 步给 A、1 步给 B，互不干扰。

于是判定条件为：

$$
\operatorname{total}(T)=\sum_{i=1}^{n}\operatorname{cost}_i(T)\ \le\ k
$$

### 3.2 $\operatorname{cost}_i(T)$ 的推导

由 $F_i(m)\ge T$ 反解最小的 $m$：

- **若 $T\le s_i$**：初始就够，一步不花 → $\operatorname{cost}_i=0$。
- **若 $T>s_i$**：$\max$ 的第一项 $s_i$ 已经 $<T$，只能靠第二项：

$$
s_i+m-2\tau_i\ge T \quad\Longrightarrow\quad m\ge T-s_i+2\tau_i
$$

$$
\boxed{\operatorname{cost}_i(T)=T-s_i+2\tau_i}
$$

**拆开看含义：**

| 部分 | 含义 |
|---|---|
| $T-s_i$ | **净赚**：和要多涨这么多，爬升期每步 +1，至少要这么多步 |
| $2\tau_i$ | **自残税**：先花 $\tau_i$ 步倒亏，破坏升序后再花 $\tau_i$ 步补回来，平白多花 $2\tau_i$ |

### 3.3 `cap` 是什么

死局实验室（$a=b=c$）的和永远是 $s$。答案要求所有实验室 $\ge T$，所以每个死局实验室都给出 $T\le s_j$：

$$
T\le \operatorname{cap}:=\min_{j\in\text{死局}} s_j
$$

> **代码里为什么看不到给死局实验室算代价？**
> 因为被 `cap` 挡住了：二分时恒有 $T\le\text{cap}\le$ 该实验室的 $s$，所以 `if (s[i] < T)` 对它**永远不成立**。
> `costBase[i] = 0` 里的那个 0 是**永远不会被用到的废值** —— 代码注释说的就是这个。

## 4. 第三层：二分答案

### 4.1 疑惑①：为什么要用二分？

#### (a) 因为"可行"随 T **单调**

记 $f(T)=\operatorname{total}(T)$。因为

$$
\operatorname{cost}_i(T)=
\begin{cases}
0, & T\le s_i \quad(\text{常数})\\[2pt]
T-s_i+2\tau_i, & T>s_i \quad(\text{斜率 }+1)
\end{cases}
$$

是**单调不减**的，相加后 $f(T)$ 也单调不减。于是可行集合

$$
\{T: f(T)\le k\}
$$

是**一段从下往上连续的前缀** $\{\dots,\ \text{ans}-1,\ \text{ans}\}$。

**二分需要的正是这个形状**：数轴上"前一半可行、后一半不可行"，每次问一个 T"行不行"，就知道该往左还是往右，一次砍一半。

> 这解释了为什么二分在这里不是"瞎猜"，而是在**找一个有序的分界点**。

#### (b) 因为别的办法都不行

- **不能枚举 T**：$k$ 到 $10^{18}$，值域太大。
- **不适合直接推公式**：$\operatorname{cost}_i$ 是分段函数，还要处理死局，讨论情况多、易错。
- **二分刚好合适**：

| 项目 | 代价 |
|---|---|
| 一次判定 `total(T)` | $O(n)$ |
| 二分次数 | $O(\log V)\approx 60$ |
| 合计 | $O(n\log V)\approx 1.2\times10^{7}$，飞快 |

> 补充：$f(T)$ 其实是**分段线性的凸函数**（每个 $\max(0,\cdot)$ 都凸），理论上可以按拐点排序做 $O(n\log n)$ 的直接解法。
> 但二分写起来短、不容易错，而 $1.2\times10^{7}$ 完全跑得动 —— 这里**简单性**压过**渐进最优性**。

#### (c) 一个容易忽略的细节：$f$ 有跳跃

$\operatorname{cost}_i(T)$ 在 $T=s_i$ 处会**往上跳**（从 0 跳到 $2\tau_i$），所以 $f$ 是不连续的"台阶状"单调函数。

**这不影响二分**：二分只需要单调性（T 可行 ⟹ 更小的 T 也可行），不需要连续。
跳跃只是让分界点落在某个台阶上而已 —— 这也对应代码里 `if (s[i] < T)` 的**严格不等号**。

### 4.2 疑惑②：`hi = min(minS + k + 1, cap)` 怎么来的？

#### (a) 先明确 hi 的职责

二分在 $[lo, hi]$ 上进行，**唯一的硬性要求**是答案落在区间内：

$$
lo\le \text{ans}\le hi
$$

- **lo 必须可行**，否则模板会答错 → 取 `lo = minS`（0 步操作时每个实验室的和都是自己的 $s_i\ge$ minS）。
- **hi 只要 $\ge$ 答案即可**，它本身可行或不可行都无所谓。因为"找最后一个可行值"的模板每一步都不会排除答案：
  - `check(mid)` 真 → $mid\le\text{ans}$ → `lo = mid` 不会越过答案；
  - `check(mid)` 假 → $mid>\text{ans}$ → `hi = mid-1` 仍 $\ge$ 答案。

所以任务变成：**找一个一定 $\ge$ ans 的数**。代码用两个来源取较小者。

#### (b) 上界 A：`minS + k`（短板论证）

盯住初始和最小的那个实验室（和 = minS）：

1. 答案要求所有实验室 $\ge T$，所以它也必须从 minS 涨到 T，**至少要涨 $T-\text{minS}$**；
2. 每次操作对它的和的改变量只能是 $-1/0/+1$，要涨 $T-\text{minS}$，**至少需要 $T-\text{minS}$ 步**（哪怕每步都恰好 +1）；
3. 总共只有 $k$ 步：

$$
T-\text{minS}\le k \quad\Longrightarrow\quad T\le \text{minS}+k
$$

> **直觉：短板理论。** 最短的板决定水面高度；要把水面抬高 $T-\text{minS}$，每步最多垫 1，只有 k 步。

#### (c) 上界 B：`cap`（死局天花板）

死局实验室永远动不了，天然规定全场最高值：

$$
T\le \min_{j\in\text{死局}} s_j = \text{cap}
$$

> **直觉：天花板。** 没有死局实验室时，`cap` 保持初始值 `LLONG_MAX`，这一重约束自动失效。

#### (d) 为什么要取 `min`，那个 `+1` 又是什么

**取 min**：两个约束必须**同时**成立，所以取交集上界。

> 老实说：**取 min 是"更紧"，不是"必需"**。只写 `hi = minS + k + 1` 结果也正确，只是区间变长、多跑几次无意义的迭代（在明显不可行的区域反复调 `total`）。

**那个 `+1`**：严格来说也**不是必需的**。因为已经证明 $\text{ans}\le\text{minS}+k$，所以 `hi = min(minS + k, cap)` 已是有效上界。
写 `+1` 只是防御性的习惯（把上界当"开区间右端点"），且在本题数据范围内**不会溢出**（$\text{minS}\ge-3\times10^9$，$k\le10^{18}$，远小于 `LLONG_MAX`≈$9.2\times10^{18}$）。

> **一句话**：A 上界管"预算够不够"，B 上界管"有没有永远动不了的实验室"，取小的那个即得安全且尽量紧的搜索上界。

### 4.3 二分模板

```cpp
while (lo < hi) {
    ll mid = lo + (hi - lo + 1) / 2;   // 上取整！
    if (total(mid) <= k) lo = mid;
    else hi = mid - 1;
}
```

这是"**找最后一个满足条件的值**"的标准写法。
`(hi - lo + 1) / 2` 用**上取整**是为了防死循环：当 `lo` 与 `hi` 只差 1 时，若取下取整会让 `lo = mid` 原地不动。
（`lo + (hi-lo)/2` 的写法避免 `lo+hi` 溢出；本题值域到 $10^{18}$ 量级，`lo+hi` 有溢出风险。）

## 5. 带逐行注释的完整代码

```cpp
#include <bits/stdc++.h>
using namespace std;
typedef long long ll;

int main() {
    int t;
    if (scanf("%d", &t) != 1) return 0;
    while (t--) {
        int n;
        ll k;
        scanf("%d %lld", &n, &k);

        vector<ll> s(n);          // 每个实验室的初始和 a+b+c
        vector<ll> costBase(n);   // 目标 T 的代价 = T + costBase[i]（仅当 T > s[i]）
        ll minS = LLONG_MAX;      // 最小的初始和：二分的下界 lo
        ll cap  = LLONG_MAX;      // 死局实验室给出的上界（无死局时自动失效）

        for (int i = 0; i < n; ++i) {
            ll a, b, c;
            scanf("%lld %lld %lld", &a, &b, &c);
            ll sum = a + b + c;
            s[i] = sum;
            minS = min(minS, sum);

            if (a == b && b == c) {
                // 死局：三个 sgn 恒为 0，和永远不变
                cap = min(cap, sum);
                costBase[i] = 0;              // 废值：T <= cap <= sum，永远不会被计入
            } else if (!(a <= b && b <= c)) {
                // 非升序（a > b 或 b > c）：tau = 0，可无限爬升
                costBase[i] = -sum;           // 代价 = max(0, T - sum)
            } else {
                // 升序非常量：要先花 tau 步自残
                ll tau = min(b - a, c - b) + 1;
                costBase[i] = -sum + 2 * tau; // 代价 = T - sum + 2*tau
            }
        }

        // 判定：让所有实验室的和都 >= T 所需最少操作数
        auto total = [&](ll T) -> ll {
            ll res = 0;
            for (int i = 0; i < n; ++i) {
                if (s[i] < T) {               // 严格小于才需要补
                    res += T + costBase[i];
                    if (res > k) return res;  // 提前截断，防止 long long 溢出
                }
            }
            return res;
        };

        ll lo = minS;                          // 下界：0 步必然可行
        ll hi = min(minS + k + 1, cap);        // 上界：短板 与 死局天花板 取小
        while (lo < hi) {
            ll mid = lo + (hi - lo + 1) / 2;   // 上取整防死循环
            if (total(mid) <= k) lo = mid;     // 可行 → 往右找更大的
            else hi = mid - 1;                 // 不可行 → f 单调，往左退
        }
        printf("%lld\n", lo);
    }
    return 0;
}
```

## 6. 易错点清单

| # | 坑 | 说明 |
|---|---|---|
| 1 | **"升序"看的是原始位置顺序** | 是 $a\le b\le c$，**不是**排序后的顺序。sgn 比较的是固定位置 $a-b$、$a-c$、$b-c$。 |
| 2 | **死局必须单拎出来** | $a=b=c$ 时既不能用 $\tau=0$，也不能套升序公式（那里 $b-a=c-b=0$ 会算出 $\tau=1$，但它其实一步都动不了）。 |
| 3 | **$\tau$ 最后的 +1 不能丢** | 光把 $b$ 压到 $a$ 仅得 $b=a$，还是升序；必须再多走一步变成严格逆序，永动机才启动。 |
| 4 | **`total` 必须提前截断** | `res > k` 就返回。$k\le10^{18}$、$n\le2\times10^5$，不截断会到 $10^{18}\times10^5$ 量级，溢出成负数 → 判定错误地返回"可行"。 |
| 5 | **全部用 64 位** | $k\le10^{18}$，答案也在 $10^{18}$ 量级。 |
| 6 | **二分用上取整** | `lo + (hi - lo + 1) / 2`，否则 `lo` 会原地打转。 |

## 8. 自测小例子（已用真程序验证）

**输入：** 2 个实验室，$k=5$；A $=(1,2,3)$，B $=(5,1,1)$

- A：$s=6$，升序，$\tau=\min(2-1,\ 3-2)+1=2$ → $\operatorname{cost}_A(T)=\max(0,\ T-2)$
- B：$s=7$，非升序（$5>1$），$\tau=0$ → $\operatorname{cost}_B(T)=\max(0,\ T-7)$

| T | cost_A | cost_B | 总代价 | $\le k=5$ ? |
|---|---|---|---|---|
| 6 | 0 | 0 | 0 | ✓ |
| **7** | **5** | **0** | **5** | **✓ ← 最大可行** |
| 8 | 6 | 1 | 7 | ✗ |
| 9 | 7 | 2 | 9 | ✗ |
| 10 | 8 | 3 | 11 | ✗ |

**答案 = 7**（程序实测输出 `7`，一致）。
T=7 时 A 的 5 步（升序 $\tau=2$，多付 4 步）+ B 的 0 步 = 5，**预算恰好用尽**。
